
## 1. Проверка среды и подготовка

| Команда | Назначение |
|---|---|
| `docker --version` | Выводит версию Docker Engine. |
| `docker compose version` | Выводит версию плагина Docker Compose. |
| `docker info` | Показывает общую информацию о Docker-демона (количество контейнеров, образов, сетей). |
| `mkdir -p ~/devops-lab4/app` | Создаёт вложенную структуру каталогов проекта (флаг `-p` не выдаёт ошибку, если каталог уже существует). |
| `cd ~/devops-lab4` | Переходит в корневой каталог проекта. |
| `touch compose.yaml .env` | Создаёт пустые конфигурационные файлы Compose и переменных окружения. |
| `touch app/app.py app/requirements.txt app/Dockerfile` | Создаёт файлы приложения, зависимостей и инструкции сборки образа. |
| `ls -la` | Выводит список файлов текущего каталога с подробной информацией (права, владелец, размер). |
| `find . -maxdepth 2 -type f -print` | Ищет все файлы в текущем каталоге и на один уровень ниже, выводит их пути. |

## 2. Валидация и запуск стека

| Команда | Назначение |
|---|---|
| `docker compose config` | Проверяет синтаксис `compose.yaml`, подставляет переменные из `.env` и выводит итоговую конфигурацию. |
| `docker compose up -d --build` | Собирает локальные образы, создаёт и запускает все сервисы в фоновом режиме (`-d`). |
| `docker compose up -d` | Запускает существующие сервисы в фоновом режиме без пересборки образов. |
| `docker compose ps` | Показывает текущее состояние сервисов стека (статус, порты, имена). |

## 3. Проверка работы приложения

| Команда | Назначение |
|---|---|
| `curl http://localhost:8080` | Отправляет HTTP-запрос к приложению и выводит JSON-ответ со счётчиками посещений. |
| `curl http://localhost:8080/health` | Проверяет эндпоинт здоровья приложения. |

## 4. Диагностика и журналы

| Команда | Назначение |
|---|---|
| `docker compose logs --tail=50 app` | Выводит последние 50 строк журнала сервиса `app`. |
| `docker compose logs --tail=50 db` | Выводит последние 50 строк журнала PostgreSQL. |
| `docker compose logs --tail=50 cache` | Выводит последние 50 строк журнала Redis. |
| `docker compose logs -f app` | Выводит журнал `app` и следит за новыми записями в реальном времени. |
| `docker compose restart app` | Перезапускает только указанный сервис `app`. |

## 5. Проверка сети и переменных окружения

| Команда | Назначение |
|---|---|
| `docker network ls` | Выводит список всех сетей, созданных в Docker. |
| `docker compose exec app getent hosts db` | Выполняет внутри контейнера `app` DNS-запрос к имени `db` и показывает IP-адрес базы. |
| `docker compose exec app getent hosts cache` | Выполняет внутри контейнера `app` DNS-запрос к имени `cache` и показывает IP-адрес Redis. |
| `docker compose exec app env \| grep -E "DB_\|REDIS_"` | Выводит переменные окружения внутри контейнера `app`, отфильтровывая только относящиеся к БД и кэшу. |

## 6. Остановка и очистка стека

| Команда                  | Назначение                                                                    |
| ------------------------ | ----------------------------------------------------------------------------- |
| `docker compose stop`    | Останавливает контейнеры, но **не удаляет** их, сети и тома.                  |
| `docker compose down`    | Останавливает и удаляет контейнеры и сеть, но **сохраняет** именованные тома. |
| `docker compose down -v` | Удаляет контейнеры, сеть и **все именованные тома** (данные будут потеряны).  |
| `docker volume ls`       | Выводит список всех именованных томов Docker в системе.                       |

## 7. Диагностика типовых ошибок

| Команда | Назначение |
|---|---|
| `ss -ltnp \| grep 8080` | Показывает, какая программа слушает порт 8080 на хосте (используется при ошибке `port is already allocated`). |
