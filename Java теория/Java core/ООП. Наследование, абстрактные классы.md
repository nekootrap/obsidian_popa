## 1. Наследование в Java
Наследование является механизмом создания нового класса на основе существующего, позволяющим повторно использовать код и функциональность родительского класса без его дублирования.

- Реализуется с помощью ключевого слова `extends`. Подкласс (потомок) получает доступ ко всем `public` и `protected` членам суперкласса (родителя).
- Члены класса, объявленные с модификатором `private`, не наследуются и остаются недоступными в подклассах. Для обеспечения доступа необходимо использовать модификаторы `default` (пакетный) или `protected`, либо предоставлять методы доступа (геттеры и сеттеры).
- При создании объекта подкласса автоматически вызывается конструктор родительского класса. Вызов осуществляется с помощью ключевого слова `super()`. Если вызов не указан явно, компилятор вставляет `super()` первой строкой в конструкторе потомка.
- Конструкторы не наследуются, но подкласс обязан инициализировать состояние родительского класса через вызов `super(...)` с соответствующими аргументами.

## 2. Переопределение и перегрузка методов

### 2.1. Переопределение методов (@Override)
Переопределение позволяет подклассу изменить реализацию метода, унаследованного от родительского класса.
- Сигнатура метода (имя, тип возвращаемого значения, список параметров) должна полностью совпадать с родительской.
- Рекомендуется использовать аннотацию `@Override`, которая обеспечивает проверку соответствия сигнатуры на этапе компиляции и улучшает читаемость кода.
- Переопределение обязательно, если родительский метод объявлен как абстрактный, или когда стандартная реализация не соответствует требованиям подкласса.
- Уровень доступа переопределяемого метода не должен быть строже, чем у исходного метода в родительском классе.

### 2.2. Перегрузка методов (Overloading)
Перегрузка позволяет определить несколько методов с одинаковым именем, но различными списками параметров (по типу, количеству или порядку).
- Возвращаемый тип может отличаться, но сам по себе не является признаком перегрузки.
- Компилятор выбирает требуемый метод на основе переданных аргументов на этапе компиляции.
- Применяется для обеспечения единообразного интерфейса при обработке разных типов данных.

## 3. Запрет наследования: модификатор final
Ключевое слово `final` используется для ограничения изменений в классах, методах и переменных:
- `final` перед объявлением класса запрещает создание его подклассов.
- `final` перед методом запрещает его переопределение в наследниках.
- `final` перед переменной делает её константой: после первоначальной инициализации значение изменить невозможно.

## 4. Абстрактные классы и методы
Абстрактные классы предназначены для описания общей структуры и поведения группы родственных классов без возможности прямого создания их экземпляров.
- Объявляются с помощью модификатора `abstract`. Попытка инстанцировать такой класс через оператор `new` приведёт к ошибке компиляции.
- Могут содержать как обычные методы с реализацией, так и абстрактные методы.
- Абстрактный метод объявляется без тела (реализации) и завершается точкой с запятой. Он также помечается модификатором `abstract`.
- Любой неабстрактный подкласс обязан реализовать все унаследованные абстрактные методы. В противном случае подкласс также должен быть объявлен как `abstract`.
- Абстракция позволяет вынести общую логику в родительский класс, оставляя специфичную реализацию для потомков, что обеспечивает гибкость и расширяемость архитектуры.

## 5. Статические члены класса (static)
Ключевое слово `static` определяет принадлежность члена класса самому классу, а не его конкретным экземплярам.

### 5.1. Статические переменные
- Являются общими для всех объектов данного класса. Изменение значения в одном экземпляре отражается на всех остальных.
- Инициализируются при загрузке класса. Доступ осуществляется через имя класса (`ClassName.variableName`). Обращение через экземпляр не рекомендуется во избежание путаницы.
- Часто используются для хранения счётчиков созданных объектов или конфигурационных параметров.

### 5.2. Статические методы
- Вызываются без создания объекта класса.
- Имеют доступ только к другим статическим членам (переменным и методам) класса.
- Не могут использовать ссылки `this` и `super`, так как не привязаны к конкретному экземпляру.
- Метод `main`, являющийся точкой входа в программу, всегда объявляется как статический.

### 5.3. Статические блоки и статический импорт
- Статический блок (`static { ... }`) выполняется один раз при первом обращении к классу (до создания объектов). Используется для сложной инициализации статических полей.
- Конструкция `import static` позволяет импортировать статические члены (методы или константы) другого класса и использовать их без указания имени класса-владельца (например, `import static java.lang.Math.PI;`).

## 6. Базовый класс Object
В Java все классы неявно наследуются от класса `java.lang.Object`. Он предоставляет базовый набор методов, доступных любому объекту.

### 6.1. Ключевые методы
- `public String toString()` — возвращает строковое представление объекта. Автоматически вызывается при передаче объекта в `System.out.println()`. Рекомендуется переопределять для вывода содержимого полей.
- `public boolean equals(Object obj)` — определяет логическое равенство объектов. По умолчанию сравнивает ссылки (`==`). Для корректной работы в коллекциях и бизнес-логике требует переопределения.
- `public int hashCode()` — возвращает хеш-код объекта (целое число). Используется в хеш-таблицах (`HashMap`, `HashSet`).

### 6.2. Контракт equals() и hashCode()
При переопределении необходимо соблюдать следующие правила:
1. Если `equals()` возвращает `true` для двух объектов, их `hashCode()` должен быть идентичен.
2. При многократном вызове `hashCode()` на одном объекте результат должен оставаться неизменным.
3. Разные объекты могут иметь одинаковый хеш-код (коллизия допустима), но это может снизить производительность хеш-коллекций.

### 6.3. Прочие методы
- `getClass()` — возвращает метаданные класса объекта во время выполнения.
- `clone()` — создаёт поверхностную копию объекта (требует реализации интерфейса `Cloneable`).
- `finalize()` — вызывается сборщиком мусора перед уничтожением объекта (в современных версиях Java признан устаревшим).
- Методы `wait()`, `notify()`, `notifyAll()` — обеспечивают механизмы межпоточного взаимодействия и синхронизации.

## 7. Основные положения
- Наследование (`extends`) обеспечивает повторное использование кода и создание иерархий классов.
- Переопределение изменяет поведение унаследованных методов, перегрузка позволяет использовать одно имя для методов с разными параметрами.
- Модификатор `final` запрещает наследование, переопределение методов или изменение значений переменных.
- Абстрактные классы (`abstract`) задают общую структуру, требуя от наследников реализации специфичной логики.
- Статические члены (`static`) принадлежат классу в целом, а не экземплярам, и инициализируются при загрузке класса.
- Все объекты в Java являются наследниками класса `Object`. Методы `equals()`, `hashCode()` и `toString()` требуют корректного переопределения для обеспечения ожидаемого поведения в коллекциях и при выводе.
